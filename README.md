# POD — custom print-on-demand store

Customers design products (T-shirts, mugs, posters…) in a browser editor, pay, and paid orders are
fulfilled by Printify.

- **Status:** Phase 1 (architecture plan) — awaiting approval. See [docs/00-MASTER-PLAN.md](docs/00-MASTER-PLAN.md).
- **Planned stack:** Next.js + TypeScript + Tailwind + shadcn/ui + Fabric.js · NestJS + Prisma + PostgreSQL · Redis + BullMQ · Cloudflare R2 · Printify API
- **Live (planned):** https://pod.supersoftltd.com
